# Sales Dashboard

## Project Description

Developed an interactive **Sales Dashboard** to analyze and visualize sales performance, revenue trends, product performance, and business insights. The dashboard helps users understand key sales metrics and make data-driven business decisions through interactive charts, graphs, and KPIs.

## Key Features

* Analyzed overall **sales, profit, and revenue performance**.
* Created interactive **KPIs and visualizations** to track business performance.
* Analyzed sales trends based on **time, products, categories, and regions**.
* Identified top-performing products and areas with strong sales performance.
* Used interactive filters and slicers for easy data exploration.
* Designed a user-friendly dashboard for quick and effective business reporting.

## Tools & Technologies

* **Microsoft Excel**
* **Data Cleaning & Data Analysis**
* **Data Visualization**
* **DAX**

## Objective

The main objective of this project is to transform raw sales data into meaningful visual insights and provide an interactive dashboard that helps businesses monitor performance, identify trends, and support data-driven decision-making.
